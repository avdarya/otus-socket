# Описание проекта

Это эхо-сервер, написанный на Python.

# Требования

- Python 3.x

# Установка

Склонируйте репозиторий и перейдите в директорию проекта.

```bash
    git clone  https://github.com/avdarya/otus-socket.git
    cd otus-socket
```

# Запуск сервера

```bash
    python3 echo_server.py
```

# Тестирование

Вы можете подключиться к серверу с помощью telnet или любого другого TCP-клиента.

Для запуска тестов используйте pytest:

```bash
    pytest
```

# Остановка сервера

Закройте терминал или нажмите Ctrl+C.
